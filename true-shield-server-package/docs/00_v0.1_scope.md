# 真信盾当前功能范围

项目已经超过最初“文本风险分析 V0.1”的范围。当前目标是形成 Android 端到后端的家庭反诈闭环。

## 已实现

1. 用户注册、登录、资料修改、密码修改和密码重置。
2. 文本、图片、语音、URL 和电话号码风险分析。
3. 规则匹配、AI 可选复核、风险解释、证据和行动建议。
4. 风险事件保存、历史、详情、统计、反馈和 PDF 报告。
5. 家庭组、邀请、成员、可信联系人和通话求助。
6. 家庭告警、自动策略、通知投递、记录和失败重试。
7. Android Compose 客户端与 FastAPI 后端。

## 尚未形成生产能力

1. 管理后台和运营审核工具。
2. 独立微服务和任务队列；当前仍是模块化单体。
3. 完整 Android 自动化测试和端到端设备测试。
4. 生产级可观测性、备份恢复、限流和密钥托管。
5. 模型训练、模型发布和线上效果评估流水线。

## 发布标准

- Ruff、后端快速测试和 Android 编译必须通过。
- 完整测试按 unit、integration、slow 三层运行。
- 数据库迁移必须可从空库顺序执行到最新版本。
- 不提交 `.env`、Firebase 配置、服务账号或本地模型。
- 风险结论必须保留非绝对化措辞与安全行动建议。
