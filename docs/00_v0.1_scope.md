# 真信盾 V0.1 开发范围

## 1. 版本目标

V0.1 的目标是完成一个可运行、可保存、可测试的文本反诈最小闭环。

用户能够输入一段可疑聊天文字，系统通过风险规则识别其中的危险特征，并输出风险等级、风险证据和可执行建议。

---

11. 历史风险事件查询

## 6. V0.1 完成标准

1. 用户可以成功注册和登录。
2. 用户可以提交一段聊天文字。
3. 系统能够返回低、中、高或未知风险。
4. 系统至少返回一条具体风险证据。
5. 高风险结果至少返回三个行动建议。
6. 系统不会使用“绝对安全”或“百分之百诈骗”等表述。
7. 分析结果可以保存并重新查看。
8. 用户不能访问其他用户的风险事件。
9. PostgreSQL、Redis 和后端能够通过 Docker Compose 启动。
10. 项目至少包含单元测试和接口测试。
