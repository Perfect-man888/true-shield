# 真信盾 API

统一前缀：`/api/v1`。除健康检查、注册、登录和密码重置外，业务接口使用 `Authorization: Bearer <token>`。

## 接口组

- `/auth`：注册、登录和密码重置。
- `/users/me`：当前用户、密码和推送设备。
- `/risk`：文本、图片、语音、URL、事件、反馈、仪表盘与报告。
- `/call-guard`：号码筛查和通话求助。
- `GET /call-guard/rules`：下载版本化 Android 离线规则包。
- `POST /call-guard/reports`：提交待复核的可疑号码、诈骗或误报反馈。
- `/families`：家庭、邀请、成员、可信联系人、告警和告警策略。
- `/health`：服务健康状态。

精确请求字段、响应字段和状态码以运行时 OpenAPI 为准：启动后访问 `/docs` 或 `/openapi.json`。客户端模型与服务端 schema 发生冲突时，以服务端 OpenAPI 和兼容性测试为判断依据。

## 错误与权限

- `401`：Token 缺失、无效、过期或认证版本失效。
- `403`：用户状态不可用或缺少家庭角色权限。
- `404`：资源不存在，或当前用户无权访问该资源。
- `409`：重复成员、邀请或其他业务状态冲突。
- `422`：请求字段或业务校验失败。

资源查询必须绑定当前用户或已验证的家庭成员身份，避免通过 UUID 枚举访问他人数据。
